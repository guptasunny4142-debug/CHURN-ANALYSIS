Project Overview
===================================================================================================================================================================
This project analysis customer churn data using Power Bi to understand customer behavior, identify churn patterns, and highlight customer segments that may require 
retention strategies. 

The dataset contain approximately **6.3k CUSTOMERS** , with 1.6k CHURNED CUSTOMERS and an overall **25.9% CHURN RATE.** The analysis explores churn across customer demographics, contracts, tenure, payment method, internet service, and other customer attributes.  

Business Objective
===================================================================================================================================================================
The main objective of this project are:
* Understand the overall customer churn rate.
* Identify customer segments with higher churn.
* Analyze how **Contract type and tenure** relate to churn.
* Understand Churn patterns across different age groups and genders.
* Analyze churn by **Payment method and internet type.**
* Examine customer service and their relationship with churn.
* Create an interactive dashboard that helps stakeholders explore churn patterns.

Data Preparation
===================================================================================================================================================================
The data was prepared in **Power Query** before creating the dashboard.

The preparation process included:
 * Checking data quality.

 * Checking appropriate data type.

Key Findings 
===================================================================================================================================================================
Some of the main findings from the analysis include:
* The overall customer churn rate is 25.9%.
* Churn can be compared across different contract type.
* Customer tenure provides an important way to examine churn behavior.
* Churn varies across different age group and customer segments.
* Payment method and internet service type can be analysis to identify segments with higher churn.
* Service-level analysis helps identify customer groups that may need further investigation for retention strategies.
